# Fonts

The game's two typefaces, shipped with it so that a first launch without a network still shows the right type.
`fonts.css` is inlined into the standalone page by `scripts/build.mjs`; the service worker caches the files.

- **Cormorant SC** (titles), by Christian Thalmann (Catharsis Fonts). SIL Open Font License 1.1.
- **EB Garamond** (text), by Georg Duffner and Octavio Pardo. SIL Open Font License 1.1.

Only the subsets the game's text needs are here: Latin, Latin Extended and Vietnamese (province and ruler names).
The licence text: https://openfontlicense.org/open-font-license-official-text/
