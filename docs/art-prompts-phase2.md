# Art prompts for Phase 2 (ChatGPT)

Sixteen images in all: 3 sheets of event paintings, 5 sheets of faces, 6 age plates and 2 title scenes.
You make them in ChatGPT; I slice the sheets, compress the tiles and wire them into the game.

## How to use this file

1. Open a new ChatGPT conversation. Attach three tiles we already have, so the style matches:
   `art/role_general.webp`, `art/unit_knights.webp`, `art/card_embassy.webp`.
2. Paste the **STYLE** block once.
3. Paste one prompt at a time, in the order given. One prompt gives one image.
4. Before saving an image, check three things: the number of tiles is right (count the rows and columns),
   the subjects are in the order asked, and there is no writing anywhere. If one fails, say
   "Redo it: exactly 3 columns and 3 rows, same subjects in the same order, no text" and try again.
5. Save each image as a PNG under the file name given above its prompt.
6. Send them to me in the chat, or put them in a folder `art/incoming/` on the branch. They need not all
   come at once.

If time is short, this is the order of value: title scenes, event sheets, Western faces, age plates,
the other four face sheets. The game works with any part of the set: where a painting is missing it
shows what it shows today.

## STYLE (paste once, first)

```
I am adding to a set of illustrations for a historical strategy game (1450–1800). The three attached
images are from the existing set. Everything you make in this conversation must look like the same
hand made them.

- Look: hand-coloured woodcut / early-modern book engraving. Bold black iron-gall ink linework with
  cross-hatching, then flat watercolour washes.
- Palette only: ink black, sepia brown, warm parchment (#f1e8d4), oxblood red (#9e1f2a), lapis blue
  (#2f5d8a), verdigris green (#3e7a3e), ochre (#c49b3a). No other colours, no gradients, no glow.
- Absolutely no text, letters, numbers, captions, labels, signatures or watermarks anywhere, and no
  writing on banners, books, papers or signs.
- Keep line weight, colouring and lighting the same in every image.
- When I ask for a grid: the tiles are equal in size, separated by thin white gaps, with no frames,
  no numbers and no titles. Draw exactly the subjects I list, in the order I list them, left to right
  and top to bottom. Do not add, drop, merge or swap subjects.

Reply "Ready" and wait for my first request.
```

## Title scenes: 2 single images

part.

```

A royal council table by candlelight, seen from slightly above: a large parchment map of the world
spread across it, sealed letters, a crown, compasses, and small carved wooden soldiers and ships
standing on the map. Behind the table a tall window opens on a harbour with ships at dawn.
Keep the upper third calm (the dark wall and the window's sky) because a title will be placed there.
```
